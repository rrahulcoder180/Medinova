# Medinova Android app

Fastest presentation approach:
1. Open Android Studio.
2. Create a new project named `Medinova`.
3. Choose Empty Views Activity.
4. Choose Java.
5. Add INTERNET permission.
6. Use the WebView code from the presentation guide.

For a real production Android app, replace the WebView with native Java screens and call the same Spring Boot REST APIs:
GET /api/medicines
POST /api/orders
